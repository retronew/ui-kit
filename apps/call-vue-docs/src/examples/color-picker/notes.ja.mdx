## 値を渡して、値を受け取る

ピッカーはすでに持っている色をハイライトする必要がありますが、その色を所有して
いるのはピッカーではなく、あなたのコンポーネントです。現在の値は `current`
prop として**渡され**、選ばれた値は Response として**返って**きます。Callable
自身は選択状態を一切保持しません。純粋な非同期関数 `(current) => Promise<next |
null>` であり、読み取り・変更・書き戻しのループ全体が一回の `await` にまとまり
ます。

`| null` は「気が変わった」分岐です。背景クリックや Esc で閉じると `null` が
解決され、呼び出し側は書き込みをスキップし、値はそのままになります。実際に選択
したときだけコミットする——だからこそ呼び出し側は結果を保存する前に `if (next)`
でガードしています。

## 使いどころ

色、アイコン、タグ、ステータス、担当者など、「既知の集合から一つの値を編集する」
あらゆる操作に使えます。現在の値を表示し、ユーザーに入れ替えさせ、実際に何かを
選んだときだけ書き戻します。
