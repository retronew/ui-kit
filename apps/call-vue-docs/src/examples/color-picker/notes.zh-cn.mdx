## 值传进来，值传出去

选择器需要高亮当前已有的颜色——但它并不拥有这个颜色，你的组件才拥有。当前值
以 `current` prop 的形式**传入**，选中的新值作为 Response **传出**，Callable
自己不保留任何选择状态。它是一个纯粹的异步函数：`(current) => Promise<next |
null>`，整个「读取—修改—写回」的循环因此收束成一次 `await`。

`| null` 是「改变主意」的分支：点击背景或按 Esc 关闭会解析为 `null`，调用方
跳过写入，值也就原封不动。只有真正做出选择才会提交——这也是调用方在存储结果前
用 `if (next)` 做判断的原因。

## 何时使用它

任何「从一组已知值中编辑一个值」的交互——颜色、图标、标签、状态、指派人。
展示当前值，让用户替换，只在他们真正做出选择时才写回。
