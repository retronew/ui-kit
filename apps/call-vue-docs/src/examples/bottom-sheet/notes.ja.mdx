## 閉じるときに下へスライドする

`call.end()` が実行された瞬間にシートが消えてしまうと、スライドして消える暇があり
ません。`createCallable` の第二引数——**アンマウント遅延**——を渡すと、終了した
Call をその時間だけマウントしたままにし、`call.ended` を公開して退出アニメーショ
ンを自分で駆動できるようになります。

```ts
const open = entered && !call.ended
// open ? 'translate-y-0' : 'translate-y-full'
```

一つの `open` フラグが両方の動きを担います。マウント後の最初のフレームで `true`
に切り替わり（スライドイン）、`call.ended` が `true` になると `false` に戻ります
（スライドアウト）——call-vue が Stack から Call を取り除く直前のタイミングです。

遅延時間は CSS のトランジション時間と揃えてください——ここではどちらも `300ms`
です。横方向のスライドで同じパターンを使う例は[設定ドロワー](/ja/examples/side-drawer)
を参照してください。
