## 调用方知道点击发生在哪里

上下文菜单必须出现在**光标所在的位置**——而光标位置唯一存在的地方，是发生在
调用现场的 DOM 事件，而不是 Callable 内部。所以调用方读取 `e.clientX` /
`e.clientY`，把它们作为普通的 `x` / `y` props 传过去；Callable 只需要把自己
`fixed` 定位到这些坐标上，完全不需要伸手去 DOM 里找指针。

这正是 `.call(props)` 在通用场景下扮演的角色：它是调用方上下文——光标位置、
被右键点击的那一行、事件携带的任何数据——进入 Callable 的接缝。事件发生在你的
组件里；`.call()` 把 Callable 需要的东西拍下快照并打开它。

## 何时使用它

只要某个界面必须锚定在一个点上出现，就可以用这个模式：右键菜单、贴着某个被点击
元素出现的浮层、从按钮弹出的选择器。触发者负责坐标，Callable 负责渲染。
