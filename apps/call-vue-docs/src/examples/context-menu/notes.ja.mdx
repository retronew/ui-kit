## クリック位置を知っているのは呼び出し側

コンテキストメニューは**カーソルの位置**に表示されなければなりません——そして
カーソル位置が存在する唯一の場所は、呼び出し元で発火する DOM イベントであり、
Callable の内部ではありません。だから呼び出し側が `e.clientX` / `e.clientY`
を読み取り、それをただの `x` / `y` props として渡します。Callable はその座標に
`fixed` でレンダリングするだけで、DOM に手を伸ばしてポインターを探す必要は
ありません。

これは `.call(props)` が一般に担っている役割そのものです。カーソル位置、右クリ
ックされた行、イベントが運ぶあらゆるデータといった呼び出し側のコンテキストが
Callable へ渡る継ぎ目です。イベントはあなたのコンポーネントで発生し、`.call()`
は Callable に必要なものをスナップショットして開きます。

## 使いどころ

ある地点に固定して表示すべき場面ではいつでも使えます。右クリックメニュー、クリ
ックした要素の脇に出るポップオーバー、ボタンから飛び出すピッカーなど。座標はト
リガーが持ち、描画は Callable が担います。
