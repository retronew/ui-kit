## promise を渡さない update はすべてに届く

`update` には二つの形があります。promise を渡すと一つの Call だけを対象にし、
省略すると新しい props が**開いているすべての Call へブロードキャスト**されます。

```ts
Upload.update({ state: 'paused' }) // 開いているすべてのピルに一括反映
```

これは浅い**マージ**であって置き換えではありません——`state` は各 Call に反映
されますが、それぞれの `label` はそのまま残ります。だからこそ「接続が切れた」
という一つのイベントで、呼び出し側が一つの promise を追いかけることなく三つの
アップロードを同時に一時停止できます。

## ブロードキャスト vs. ターゲット指定

これは[ライブステータス更新](/ja/examples/live-status)の逆のパターンです。

- **ターゲット指定**——`update(promise, props)` は呼び出し側が追跡している
  特定の一つの Call だけに送ります。それぞれの Call が独自のライフサイクルを
  持つ場合に使います。
- **ブロードキャスト**——`update(props)` はすべてに送ります。接続状態やグロー
  バルなモード、共有の時計など、開いているすべての Call が反映すべき環境的な
  状態に使います。

## 注意点

- マージであるということは、部分的なブロードキャストが触れなかった props は
  そのまま残るということです——便利ですが、古い Call がまだ持っている prop に
  依存していないか確認してください。
